# Gemini 모델 선택 가이드 (Model Selection Guide)

에이전트에 할당할 모델은 작업의 **복잡도, 추론 깊이, 실행 주기, 응답 속도 및 비용 효율성**에 따라 전략적으로 배분한다.

---

## 1. 모델 티어 결정표

| 모델 티어 | 권장 모델 | 강점 및 성격 | 최적 배정 업무 |
| :--- | :--- | :--- | :--- |
| **추론 티어 (Reasoning Tier)** | **Gemini 3.8 / 3.0 Pro** | 깊은 논리적 추론, 장기 계획 수립, 복잡한 시스템 아키텍처 설계, 비판적 코드 검증 | - 시스템/도메인 아키텍처 설계<br>- 적대적 검증자(Adversarial Reviewer)<br>- 고난도 보안/동시성 로직 구현<br>- 종합 회고 및 하네스 진화(Evolve) |
| **실행 티어 (Execution Tier)** | **Gemini 3.8 / 3.0 Flash** | 초고속 응답, 대규모 컨텍스트 윈도우 처리, 높은 처리량, 비용 효율성 | - 컴포넌트 마크업 및 스타일링<br>- 정적 분석 및 린트 오류 수정<br>- 단위 테스트 작성 및 실행 로그 분석<br>- 문서화, 형식 변환, 파일 탐색 |

---

## 2. 세부 선택 기준

### 2-1. Gemini Pro (Reasoning Tier)를 선택해야 하는 경우
1. **장기적이고 복합적인 의사결정**:
   - 모호한 비즈니스 요구사항을 기술 스펙으로 분해해야 할 때.
   - 데이터 모델 간의 외래키 관계, 트랜잭션 경계, 캐싱 전략 등을 종합 설계할 때.
2. **엄격한 품질 및 보안 검증**:
   - 경쟁 조건(Race condition), 인증/인가 취약점, 메모리 누수 등을 심층 점검할 때.
   - 복수의 구현 대안을 놓고 심사위원단(Judge Panel) 역할을 수행할 때.

### 2-2. Gemini Flash (Execution Tier)를 선택해야 하는 경우
1. **신속한 피드백 루프**:
   - TDD 사이클에서 빠르게 테스트를 통과시키는 코드 작성.
   - 브라우저 서브에이전트 조작 및 DOM 상태 확인.
2. **다량의 파일 스위핑 및 변환**:
   - 수십 개의 레거시 파일 마이그레이션.
   - 에러 로그 파싱 및 통계 집계.
