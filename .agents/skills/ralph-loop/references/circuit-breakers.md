# 서킷 브레이커 & 안전 제동 장치 (Circuit Breakers & Safety Ceilings)

자율 루프는 강력하지만 적절한 제어 장치가 없으면 무한 루프, 리소스 고갈, 불필요한 비용 발생을 유발할 수 있다. 본 문서는 루프 엔지니어링의 필수 안전장치를 규정한다.

---

## 1. 4대 안전 제동 장치

### 1-1. 최대 반복 상한 (Max Iterations Ceiling)
- 모든 루프는 예외 없이 **`max_iterations`** 상한을 갖는다.
- 기본 권장값:
  - 단순 버그 수정 / 린트 수렴: 5회
  - 컴포넌트 단위 TDD: 10회
  - 대규모 PRD 태스크 소진: 15회
- 상한 도달 시 루프는 즉시 중단되고 현재까지의 중간 산출물과 미완료 태스크 목록을 사용자에게 보고한다.

### 1-2. 무진전 감지기 (No-Progress Detector)
- $K$회(기본 2회) 연속으로 다음 상태가 감지되면 서킷 브레이커가 작동한다:
  1. 남은 에러 개수가 줄어들지 않음 ($E_t \ge E_{t-1} \ge E_{t-2}$)
  2. 디스크 상의 파일 변경(Git diff)이 전혀 없음
  3. 동일한 컴파일/런타임 에러 스택트레이스가 반복됨
- 대응: 에이전트는 동일 접근법을 중단하고 전략을 수정하거나 사용자에게 에스컬레이션한다.

### 1-3. 타임아웃 펜스 (Timeout Fence)
- 단일 턴 실행 시간: 최대 5분 초과 시 자동 중지.
- 전체 루프 실행 시간: 장기 배치 작업의 경우에도 지정된 시간(예: 30분) 초과 시 자동 체크포인트 저장 후 중단.

### 1-4. 롤백 안전망 (Git Rollback Net)
- 루프 시작 시점의 Git 상태를 기록한다 (`git branch backup-loop-checkpoint`).
- 루프 진행 중 심각한 코드 오염이나 회귀(Regression)가 발생하여 복구가 어려울 경우, 마지막 정상 체크포인트로 안전하게 롤백할 수 있는 명령을 제공한다.
